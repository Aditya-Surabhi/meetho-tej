# meetho-tej

Everything behind [@meetho.tej](https://www.instagram.com/meetho.tej/), a series of Telugu reels called **Deep Things**.

**In one line:** short Telugu reels about people. You watch one, think "that's my friend," and send it to them.

**The mission:** I say the things people feel but rarely say out loud, in Telugu. Each reel is about one type of person, so you see yourself, or someone you love, a little differently.

**Watch the reels: [instagram.com/meetho.tej](https://www.instagram.com/meetho.tej/)**
